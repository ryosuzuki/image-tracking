# Paper ID placement samples

30 visual concepts preserving four black L corners and page-content-independent IDs.
5 standard version-1 QR samples contain paper-001 through paper-005; remaining 25 custom concepts do not yet have decoders and are not QR/AprilTag/ArUco. No physical-device performance claims are made.

Gallery is standalone inline HTML/SVG. Print stylesheet produces one card per page. Source generator is build.py; needs Pillow and qrcode.

Ownership: thirty_id_samples. Integration target: origin/main. Authoritative path: docs/paper-id-samples/. Validation: 30 articles, 6 groups of 5; standard QR matrix generated by qrcode. Preview PNG and PDF outside repo in dated flat stuff directory.

## Implemented top-edge color DASH reader

color-camera.html + color-detector.mjs + color-code.mjs: 30 exact-only IDs, 6 quaternary data symbols plus weighted mod-4 checksum. Codebook minimum Hamming distance 3. Unknown, uncertain, or non-codebook patterns rejected; no automatic correction. Black start/end marks and cyclic/winding trials establish orientation. Four L corners feed OpenCV homography; only top strip is sampled, interior is not matched.

Targets: 640×880 raster; L centers (25,25) etc with stroke12; detected inner corners (31,31) etc. Color dashes x110+58i, y51, size40×24, 7 symbols. Four palette colors #d52d36 #166bd0 #e0ae09 #168e56. Full page camera/performance unmeasured at publication.

Synthetic browser tests: 40/40 (30 IDs, blank interior, ambiguous gray rejection, 90/180/270 rotation, blank and missing-corner rejection, code distance, all 630 single-symbol substitutions, neutral rejection). Direct prior-art pointers: https://dynamicland.org/archive/2016/Framecodes and https://dynamicland.org/archive/2017/Dotframes. Independently implemented experimental design, not official Dynamicland.
