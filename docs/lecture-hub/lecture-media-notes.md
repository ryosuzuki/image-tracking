# MR Image Tracking: initial lecture media collection

**Status:** 18 curated source-backed examples; bounded initial collection, not an exhaustive literature review. Fourteen authentic visuals were privately downloaded, decoded, hashed, and inspected. Public hub should embed original remote images with visible attribution rather than redistribute source pixels where permissions remain unclear. MagicBook's figure extraction is private verification only; link the original PDF publicly.

## Suggested lecture sequence

1. **Paper as an interface:** DigitalDesk (1991), metaDESK / Tangible Bits (1997), I/O Bulb / Luminous Room (1998; Urp paper 1999).
2. **Make tracking concrete:** ARToolKit (1999), MagicBook (2001), ArUco (2014). Explain identity versus corners/pose, camera calibration, physical marker size, and stable registration.
3. **Tangible and projected futures:** Tangible Viewpoints (2001), Illuminating Clay (2002), SandScape (2003), I/O Brush (2004), Dynamicland (2024 introductory video with a separately linked 2018 talk).
4. **Research interaction patterns:** Printed Paper Markers (2020), RealitySketch (2020), Dually Noted (2022), Opportunistic Interfaces (2022), RealityCanvas (2023), Teachable Reality (2023), Marking Material Interactions (2023).
5. **Bridge to a student demo:** Start with one known marker and one anchored model, then multiple cards, a paper mechanism, interaction, capture, and replay. Do not imply all surveyed systems are implementable by a single image tracker.

## Technical category boundaries

- **Fiducial tracking:** ARToolKit, MagicBook, ArUco, Printed Paper Markers. Dynamicland also illustrates tagged physical materials and projection, but its complete environment is not equivalent to a headset marker demo.
- **Document/image augmentation:** Dually Noted.
- **Markerless/object tracking and authoring:** Opportunistic Interfaces, RealitySketch, Teachable Reality; distinguish classification/recognition from continuous 6DoF pose.
- **Adjacent physical/projection interfaces:** metaDESK, I/O Bulb, Tangible Viewpoints, Illuminating Clay, SandScape, I/O Brush. Tangible Viewpoints source explicitly says wirelessly sensed pawns; Illuminating Clay concerns scanned 3D geometry; I/O Brush camera sampling is not object pose tracking.

## Identity and acquisition gaps

- **“Magic Ink”:** MagicBook is a plausible candidate only. The actual 2001 MagicBook paper was inspected. Do not silently rename the remembered work. “Magic Paper” has not been independently verified in this collection.
- **Ishii projected storytelling:** Tangible Viewpoints is a source-verified candidate; the exact remembered project remains unresolved.
- **“Johannes / Lope” and paper visualization:** exact authors/title unresolved.
- **Pokémon-card AR:** exact application or clip unresolved. Pokémon GO is not an acceptable replacement. No franchise asset has been downloaded or reproduced.
- **ArUco bird / animated 3D paper:** exact paper unresolved. Do not substitute mechanical PaperMech or assume Printed Paper Markers is the intended animation paper.
- **Clement Zheng / Ellen Do:** Tangible Interfaces with Printed Paper Markers (DIS 2020) identity and DOI verified; Marking Material Interactions with Computer Vision (CHI 2023) identified in the local conference corpus. Author website returned HTTP 429; original media not acquired yet.
- **DigitalDesk:** exact 1991 paper and 1993 continuation verified through Crossref. Authentic image/video still missing.
- **ARToolKit:** original Washington HITL archive verified; authentic remote visual/video acquisition still incomplete.

## Asset quality and provenance

- MIT project badges for metaDESK, Tangible Viewpoints, Illuminating Clay, and SandScape are genuine but only approximately 180–204 pixels despite width parameters. Label as thumbnails; source-linked Vimeo clips provide better classroom visuals.
- I/O Brush project page displays a CC BY-NC-ND 3.0 badge for photos. Use an unmodified, attributed original for noncommercial teaching; confirm scope before broader redistribution.
- OpenCV ArUco visual comes from the official OpenCV source repository. Retain attribution/license when copying.
- Other original project media carry source attribution but no verified redistribution license in this collection. Remote embeds avoid copying but are not a claim of blanket reuse permission.
- Video links are verified as linked by the canonical project page. Playback has not been tested in this collection.
- The similarly named `duallynoted.github.io` was inspected and rejected: it is an unrelated project. Correct Dually Noted canonical publication is Adobe Research, DOI `10.1145/3491102.3502026`.
