# Paper Content Lab

Black L-corner tracking plus on-demand, browser-local English OCR. Actual rectified image pixels are read by Tesseract.js; no target IDs determine the result. SUN/TREE/MUSIC and arithmetic trigger simple tracked 2D visuals, and other text is displayed literally.

Open `targets.html` on a laptop and `index.html` on a rear-camera phone. Press Read after the sheet is detected. Read again after changing content. Models load from public CDNs; images are not uploaded. A photo input allows reproducible non-camera tests.

The nearest-center association is not a persistent ID: crossing or replacement can misassociate. Results clear after sustained tracking loss or a large jump. Printed English is the supported baseline; handwritten recognition is not guaranteed, arbitrary drawing semantics are not implemented. No automatic change detection or calibrated 3D.
